# Scarp Compiler & Runner v0.1.6 — Experimental Pre-release

The official experimental [Scarp](https://github.com/scarp-lang/scarp) extension for Visual Studio Code adds compiler-managed workflows and improved editor assistance. **This release remains experimental**: the Scarp compiler is installed separately, and no source runs automatically.

## What's new

- **Run Workspace Entry (compiler alpha.18+):** explicitly choose an opened, trusted local VS Code workspace and run the official `scarp exec` default entry. The extension probes real compiler capability, checks unsaved/stale source, and prevents duplicate launches.
- **Persistent arrays (alpha.18+):** editor-only syntax coloring, completion, hover and signature help for `array_set(values, index, replacement)`, which returns a new immutable array. Versioned help documents bounds and memory quotas.
- **Dedicated lowercase `scarp.project` manifest editing:** v2-specific TextMate syntax, normal `//` line comments, brace-aware editing and an opt-in `sproject` snippet. This does **not** migrate old manifests or validate projects. Published alpha.20 scaffolds lowercase v2; alpha.19 and older binaries may create legacy uppercase `Scarp.project`.
- **Explicit project actions:** modern initialization, project test and filtered test commands, safe read-only discovery, project module/symbol browsing and compiler error explanations. Opt-in per-file Run/Verify CodeLens is disabled by default.
- **Richer editing for Scarp:** versioned compiler-free help for BigInt, exact decimal, typed collections, records, variants, Option/Result, Unicode, arrays and scientific/bitwise functions. Local Outline covers additional top-level declarations. Runtime support always depends on the installed compiler.
- **Safer setup and management:** explicitly requested compiler setup and native downloads with SHA-256 verification, cancellable operations, manual compiler discovery and update checking. No background installations, automatic source evaluation or invisible update polling.

- **Published alpha.20 editing:** distinct TextMate coloring for exact lowercase-suffixed decimal literals such as `0.1d` (unsuffixed `0.1` remains binary64), plus opt-in snippets for exact decimal arithmetic and persistent mutable-tuple member replacement. Both require an installed alpha.20+ compatible compiler; editor hints do not execute code.

## Qualification

- The pre-release workflow pins the independently published **Scarp v0.0.6-alpha.19** compiler and its exact source commit, preserving historical compiler compatibility jobs.
- An independent alpha.20 source-compatibility job checks real CLI execution, project initialization, unit tests and VS Code Extension Host without publishing a package.
- Native installation CI exercises actual published alpha.17 and alpha.19 downloads, separately pinned archive and checksum SHA-256 digests, offline reuse, and the real VS Code Extension Host on supported Windows, Linux and macOS runners.
- The existing pre-release qualification gate statically verifies the original **26** Scarp source snippets; an additional alpha.20 CI job verifies all **28** snippets and exercises alpha.18 default entry and array update golden output, full type/lint/unit checks, trusted VS Code Extension Host, and Restricted Mode.
- The `scarp-0.1.6.vsix` package must include all required grammar/snippet assets, match publisher `ScarpLang` and version `0.1.6`, carry the VS Code prerelease marker, and pass ZIP and provenance checks.

## Requirements and limitations

**VS Code 1.96.0+** is required. Use a supported official Scarp compiler build in the extension host (Windows x64, Linux x64 and Apple Silicon macOS have published native packages), or explicitly set `scarp.compilerPath`. Scarp alpha.19's host callable APIs are Rust embedding features; they do **not** add closures, function-as-value syntax or indirect source calls.

This release does not provide a language server, semantic type checking in the editor, automatic project execution, native executable generation or a stable API/ABI. Stable extension publication remains blocked until the Scarp compiler ships its first independently verified stable release.
