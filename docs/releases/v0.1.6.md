# Scarp Compiler & Runner v0.1.6 — Development draft

**Not published.** v0.1.5 is the latest approved experimental pre-release.
Do not create a stable extension release before the official Scarp compiler
has its first verified stable release.

## Scope in this development branch

- Increment the VS Code extension package version to numeric `0.1.6`.
  The prior immutable `v0.1.5` tag and published VSIX remain unchanged.
- Provide on-demand native VS Code **Signature Help** for the 18 functions
  documented from official Scarp compiler alpha.3 through alpha.6.
  Examples: `top_p(probabilities, mass)`,
  `softmax_temp(scores, temperature)` and `text_replace(value, search, replacement)`.
- Add native VS Code **Completion Items** for matching published built-in function names after a minimum two-letter prefix. Reuse versioned signatures and compiler constraints without invoking Scarp or suggesting arbitrary user declarations. Do not insert argument expressions automatically.
- Track the active argument through nested function calls, tuple/vector
  literals and alpha.7 conditional-value blocks. Refuse hints inside quoted
  text, comments, declarations and qualified calls.
- Keep the source scan bounded to the most recent 24 lines and 16,384 UTF-16
  code units, with a maximum of 128 nesting levels. No compiler process,
  background analysis, network call or workspace trust is required.
- Unit-test malformed source, nesting, old-version metadata, UTF-16 strings,
  active argument selection and false-positive suppression.
- Exercise the actual VS Code signature-help API in both trusted and
  Restricted Mode Extension Hosts; the Restricted Mode case must prove no
  compiler executable was invoked.

## Release safety

- No `v0.1.6` release tag, VSIX publication, or registry push is
  authorized by this development PR.
- The `docs/releases/v0.1.6-public.md` file is intentionally absent.
  Manually approved publication requires reviewed public notes and a fresh
  successful independent pre-release qualification workflow.
- The existing compiler alpha.1–alpha.7 compatibility matrix, v0.1.5
  pre-release provenance, Open VSX token preflight and safety gates remain.
