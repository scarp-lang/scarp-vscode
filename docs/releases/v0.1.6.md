# Scarp Compiler & Runner v0.1.6 — Development draft

**Not published.** v0.1.5 is the latest approved experimental pre-release.
Do not create a stable extension release before the official Scarp compiler
has its first verified stable release.

## Scope in this development branch

- Increment the VS Code extension package version to numeric `0.1.6`.
  The prior immutable `v0.1.5` tag and published VSIX remain unchanged.
- Add an opt-in `scarp.showFileActionsCodeLens` editor setting (default false). When enabled in trusted workspaces, per-file CodeLens commands offer Run and Verify without opening the Command Palette. The provider never starts a process, and each clicked action targets the URI in its CodeLens, not an unrelated active tab. Old compilers may evaluate during the existing legacy `check` fallback.
- Provide on-demand native VS Code **Signature Help** for the 18 functions
  documented from official Scarp compiler alpha.3 through alpha.6.
  Examples: `top_p(probabilities, mass)`,
  `softmax_temp(scores, temperature)` and `text_replace(value, search, replacement)`.
- Add native VS Code **Completion Items** for matching published built-in function names after a minimum two-letter prefix. Reuse versioned signatures and compiler constraints without invoking Scarp or suggesting arbitrary user declarations. Do not insert argument expressions automatically.
- Track the active argument through nested function calls, tuple/vector
  literals and alpha.7 conditional-value blocks. Refuse hints inside quoted
  text, comments, declarations and qualified calls.
- Keep the source scan bounded to the most recent 24 lines and 16,384 UTF-16
  code units, with a maximum of 128 nesting levels. No compiler process,
  background analysis, network call or workspace trust is required.
- Unit-test malformed source, nesting, old-version metadata, UTF-16 strings,
  active argument selection and false-positive suppression.
- Exercise the actual VS Code signature-help API in both trusted and
  Restricted Mode Extension Hosts; the Restricted Mode case must prove no
  compiler executable was invoked.

## Published alpha.20 alignment (nonpublishing)

- Highlight lowercase exact decimal literals (`42d`, `0.1d`) as complete numeric tokens. Keep unsuffixed binary64 floats unchanged and do not mark invalid uppercase or exponent suffixes as decimal.
- Add two explicit version-gated snippets for exact decimal literal arithmetic and persistent replacement of a mutable tuple member. The compiler validates tuple shape, index, types and allocation quotas.
- Add an independent immutable published `v0.0.6-alpha.20` compiler compatibility job. It verifies all 28 snippets, decimal/tuple execution and invalid numeric mixing, lowercase v2 initialization, and the actual VS Code Extension Host. Historical alpha.17/alpha.19 native archive qualification remains intact.
- This does not publish v0.1.6, alter an existing registry version, or replace the separately reviewed pre-release publishing gate.

## Nested workspace navigation and native editing additions

- Added native Scarp code folding and Expand Selection, lexical UTF-16 structural snapshots with cache and strict source/complexity limits. No compiler process is invoked by editor folding or range selection, including Restricted Mode.
- Added trusted-workspace local import links with filesystem containment, symlink/path safety and missing-module fallback.
- Added **Browse Local Workspace Imports** and **Browse Nested Workspace Projects** commands. The project picker supports many independent subprojects in one opened folder, v2 lowercase `scarp.project` and historical uppercase `Scarp.project`, source-tree navigation and read-only opening of nested `.srp` files.
- Added bounded lexical module dependency reports (including cyclic and missing imports), source metrics and an unsaved Markdown report. Static graph reports are editor hints rather than semantic compiler validation.
- Added broad Node regression suites and real VS Code host/Restricted Mode testing. PR #112 merged over **5,000** added lines into `main`, passing the full 33-job CI matrix.
