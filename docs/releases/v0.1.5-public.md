# Scarp Compiler & Runner v0.1.5 — Experimental Pre-release

Scarp Compiler & Runner is the official experimental VS Code extension for the
[Scarp language](https://github.com/scarp-lang/scarp). This version strengthens
stale-result protection, cancellation, developer navigation and compatibility
with the published **Scarp v0.0.6-alpha.5** compiler. It is **not a stable
extension**, a separate compiler, or a language server.

## Changes in v0.1.5

- **Safer Run Current File:** cancel pending compiler probes and refuse a new
  terminal when the selected saved source changes, closes, or is externally
  rewritten during startup. Running terminals and unrelated files are unaffected.
- **Safer project launching:** detect dirty project buffers, source or manifest
  edits during compiler capability checks, and bounded external disk changes
  before opening the interpreter terminal.
- **Cancel outdated verification:** stop obsolete standalone-file or project
  verification subprocesses when relevant sources change or the configured
  compiler switches. Discard their stale results rather than publishing false
  Problems. Unrelated checks remain independent.
- **On-demand navigation:** cancel obsolete Go to Definition and Find All
  References requests on source edits, closure, workspace changes or user
  cancellation. Navigation continues to use the official static compiler
  reference index, not an always-running language server.
- **Opt-in verify on save:** disabling `scarp.verifyOnSave` cancels an
  automatic check without interrupting a separately requested manual check.
  Rapid saves preserve the newest verification request.
- **Official compiler alpha.5 compatibility:** preserve independent alpha.1
  through alpha.4 gates and add published alpha.5 CLI, project, static
  symbol/reference JSON, interpreter and real VS Code Extension Host tests.
  Compare Top-K, temperature, sampled calculus, cumulative area, cosine
  similarity, nucleus selection and Pearson correlation examples against
  their exact tagged compiler fixtures.
- **Updated syntax highlighting:** recognize published alpha.3 numerical calls
  and alpha.4 `sample_area`, `sample_slopes`, `sample_cumulative_area`
  and `cosine_similarity`, plus alpha.5 `top_p`, `top_p_values` and
  `pearson_correlation`, only in actual call positions, not declarations,
  strings, comments or longer identifiers. This does not imply runtime support
  when users have older compilers installed.
- **Release integrity:** validate VSIX structure, reject unsafe or ambiguous
  ZIP members, require exact source-tag provenance and compare any existing
  GitHub release asset against the independently verified package.

## Installation and compatibility

- Requires **VS Code 1.96.0+**.
- Install the official Scarp compiler separately in the active VS Code
  extension-host environment or configure `scarp.compilerPath`.
- Navigation requires **Scarp v0.0.6-alpha.1+**. Top-K and temperature
  helpers require alpha.3+, while sampled calculus and cosine similarity
  require the published alpha.4 compiler or a verified later build.
  Nucleus selection and Pearson correlation require alpha.5 or later.
- The extension identifier is `ScarpLang.scarp` for Visual Studio Marketplace
  and Open VSX.
- In Restricted Mode, compiler-backed and execution commands remain disabled;
  syntax highlighting and local Outline remain available.

## Limitations

This pre-release does **not** add native executable generation, a `scarp
compile` command, a language server, background semantic indexing, code
completion, a package manager, a stable ABI, or a GPU runtime. Project Launch
uses the official Scarp interpreter. Static verification never executes normal
runtime statements.

The stable extension release gate remains closed until the official Scarp
compiler has its first independently verified stable release.
