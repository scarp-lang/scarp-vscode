# Scarp Compiler & Runner v0.1.3 — Experimental Pre-release

This release adds practical Scarp editor navigation and safe, opt-in static verification when saving source files. The extension and compiler remain **experimental**, not stable.

## Highlights

### Outline and Go to Symbol in Editor

- Browse file-level `funcra` functions, including `pure funcra` and public function exports.
- Navigate `bind` immutable declarations, `var` mutable declarations, public `pub bind` exports, and `import "..." as alias` module imports.
- Navigate to the exact name selection, with declaration ranges spanning complete function bodies.
- Tolerant local parsing ignores fake declarations in strings/comments and handles source files while you type. It does not execute source code or require the compiler.

### Optional Verify on Save

- Enable **`scarp.verifyOnSave`** in VS Code settings to run automatic checks when saving a local `.srp` file. The setting defaults to **off**.
- Automatic checks use only the official compiler's non-executing `scarp verify --diagnostic-format=json` command (supported in v0.0.5-alpha.3 and later).
- Older Scarp compilers with only an evaluating `check` command are **never executed automatically** on save.
- Rapid saves are debounced; checks for the same file are serialized, and stale diagnostic updates are discarded. Results appear quietly in Problems and the Scarp Output channel.

### Quality and compatibility

- Cross-platform CI builds and tests on Linux, Windows and macOS.
- Real VS Code Extension Host integration tests check Outline results and verify-on-save with the pinned official compiler.
- Existing syntax highlighting, compiler-backed Run and Verify commands, pre-release packaging checks and independent file diagnostics remain supported.
- Official compiler compatibility target: **Scarp v0.0.5-alpha.3**. VS Code **1.96.0+**.

## Install

Use the **Pre-release** channel for `ScarpLang.scarp` on Visual Studio Marketplace or Open VSX, or install `scarp-0.1.3.vsix` from this GitHub Release.

You must install the official Scarp compiler separately to run or verify Scarp programs. Set `scarp.compilerPath` if the binary is not on the extension host's PATH.

## Not yet supported

The official Scarp compiler is still alpha. The extension does **not** claim native executable compilation, project builds, debugging, AI code completion, or a stable release. Stable extension publication remains blocked until the Scarp compiler's first verified stable release.
