# Scarp Compiler & Runner v0.1.2 — Experimental Pre-release

This release brings the first native Scarp syntax highlighting to VS Code and improves the reliability of compiler-backed diagnostics. **Scarp and this extension remain experimental.**

## What's new

- **Real Scarp syntax highlighting.** New TextMate grammar for `.srp` files, aligned with the official Scarp v0.0.5-alpha.3 lexer and parser: `bind`, `var`, `funcra`, `pure`, `pub`, `import`, flow control, types, boolean literals, built-in output calls, function calls, strings and supported escapes, decimal/float/hex/binary numbers, line comments and operators.
- **Independent Problems per file.** Checking one source no longer clears unrelated source diagnostics. Imported-file errors retain their verification owners.
- **Stale diagnostics protection.** Editing a source invalidates its affected Problems, and results from a verification of an outdated document are discarded.
- **Release-safe packaging.** CI tests grammar tokenization using real TextMate/Oniguruma and confirms the grammar is in the VSIX. Cross-platform, official compiler and real VS Code Extension Host checks are required.

## Compatibility and limitations

- Official compiler integration tested against **Scarp v0.0.5-alpha.3**. Install the separate compiler and set `scarp.compilerPath` if it isn't on `PATH`.
- VS Code **1.96.0 or newer**, including editors compatible with VS Code extensions.
- `Scarp: Verify Current File` uses non-executing `verify` when available. Older Scarp builds fall back to the evaluating `check` command.
- `Scarp: Run Current File` runs the official Scarp interpreter. No native Scarp executable compilation, project builds, code completion, or debugging is claimed.

## Install

Install the **pre-release** for `ScarpLang.scarp` from Visual Studio Marketplace or Open VSX, or install the attached `scarp-0.1.2.vsix` via VS Code's **Extensions → Install from VSIX** menu.

This is **not a stable release**. Stable extension publishing remains blocked until the official Scarp compiler reaches its first stable release.
